Você está trabalhando no sistema **curti Z**.

Quero uma melhoria estrutural e visual completa dos painéis do sistema, usando o **Painel do Cliente atual como principal referência visual e de UX**.

Hoje os painéis possuem estilos diferentes entre si.

Quero corrigir isso.

# 5. FOTO DE PERFIL

Essa funcionalidade é obrigatória.

Todos os usuários dos painéis devem possuir suporte a foto de perfil.

Painéis:

* Cliente
* Representante
* Administrativo
* Gerencial
* Operacional

A foto deve aparecer em formato:

**circular**

Exemplo visual:

```text
   ●
 José
```

Quando houver foto:

* exibir a foto;
* recortar visualmente em círculo;
* usar `object-fit: cover`;
* preservar proporção;
* tamanho adequado ao local.

Quando não houver:

usar fallback com:

* inicial do nome;
  ou
* avatar padrão existente.

---

# 6. PERFIL ÚNICO DO USUÁRIO

IMPORTANTE:

Não criar perfis separados desnecessariamente.

A foto deve pertencer ao **usuário**, não à role.

Exemplo:

José possui uma conta curti Z.

José adiciona sua foto no perfil.

Se José também for representante, a mesma foto deve aparecer:

* Área do Cliente;
* Painel do Representante.

Não duplicar a imagem.

Não criar uma segunda foto específica apenas para representante.

A origem deve ser a mesma informação de perfil.

---

# 7. FOTO NO SUPABASE

Analise a estrutura existente antes de criar migrations.

Se já existir campo adequado para avatar, utilize-o.

Se não existir, implemente corretamente.

Exemplo conceitual:

```text
profile.avatar_url
```

ou estrutura equivalente já usada pelo sistema.

Não crie campos duplicados como:

```text
customer_avatar
representative_avatar
admin_avatar
```

O avatar pertence ao usuário.
