# Referências visuais

As dez telas desta pasta foram fornecidas como direção visual para a implementação da Curtiz.
Elas não são telas de produção nem uma afirmação de que produtos, integrações, lojas ou dados
mostrados nas imagens existam.

A identidade usada no projeto é provisória e substituível. O ativo oficial da marca deverá
substituí-la antes da publicação.

3. Carrinho

10. Painel técnico

`provisional-logo-concept.png` é somente um estudo visual gerado para exploração interna. O
componente vetorial substituível usado nas aplicações também é explicitamente provisório.
