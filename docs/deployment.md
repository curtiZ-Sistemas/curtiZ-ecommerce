# Deploy

Referência: dois projetos Next.js, Supabase gerenciado e Cloudflare. Crie ambientes local, staging e produção com projetos Supabase separados. Execute migrations por CI após dry-run e aprovação.

O validador de produção falha quando encontra demo, provider de pagamento mock, HTTP, MFA interno desativado ou variáveis essenciais ausentes.
